# Argus Support

This is the public support and Marketplace-asset repository for the
[Argus VS Code extension](https://marketplace.visualstudio.com/items?itemName=petar-s-dimov.argus-worktree-agent-sessions).
The extension source is maintained separately.

## Report a problem or request a feature

Open an [issue](https://github.com/petar-s-dimov/argus-support/issues) and
include:

- Your operating system and VS Code version.
- The Argus, Claude Code, and/or Codex extension versions.
- The exact action you took and what happened.
- Whether the problem followed a VS Code reload or extension update.
- Relevant messages from **View → Output → Argus**.

Remove credentials and private information before posting. Do not attach
private prompts, complete provider session files, or repository contents.

## Security

Do not disclose a vulnerability or credential in a public issue. Use
[GitHub's private vulnerability report](https://github.com/petar-s-dimov/argus-support/security/advisories/new)
instead.
